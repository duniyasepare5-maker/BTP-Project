A complete, scientifically reliable, reproducible, and physically constrained machine learning prediction and parametric analysis system for **Disconnected Piled Raft Foundations (DPRF)** embedded in cohesionless soils, calibrated on published experimental research from **Halder & Manna (*Acta Geotechnica* 2021, 2022)** and established literature benchmarks.

---

## 🏛️ Geotechnical Problem & Scientific Background

In conventional **Connected Piled Raft (CPR)** systems, piles are rigidly connected to the raft, forcing equal settlement ($w_r = w_p$) and causing severe axial and shear stress concentrations at the pile heads. 

In a **Disconnected Piled Raft (DPRF)** system:
- Piles are disconnected from the raft by an engineered **granular cushion layer** (Load Transfer Platform, LTP).
- Piles function primarily as **settlement-reducing ground reinforcements**.
- Superstructure load is redistributed through granular cushion arching and shear interlock, reducing pile head stresses by over $60\%$ and permitting a lower factor of safety ($FS \approx 1.3$ vs $4.0$).
- **Inverted Kinetics**: The raft carries $95\text{--}100\%$ of load initially; pile contribution mobilizes gradually with settlement.
- **Negative Skin Friction**: Downward settlement of the cushion/subsoil relative to the pile generates negative skin friction in the upper shaft, shifting maximum axial pile load downward to the neutral plane at depth $z_n \approx 10d$ ($0.25\text{ m}$).

---

## ⚖️ Physical Laws & Constraints Enforced

Every prediction generated by this system strictly obeys geotechnical static equilibrium:
1. **Total Load Equilibrium**:
   $$Q = Q_r + Q_p$$
2. **Load-Sharing Proportions**:
   $$\alpha_p = \frac{Q_p}{Q} \times 100\%, \quad \alpha_r = \frac{Q_r}{Q} \times 100\%, \quad \alpha_p + \alpha_r = 100\%$$
3. **Physical Bounds**:
   $$0\% \le \alpha_p \le 100\%, \quad 0\% \le \alpha_r \le 100\%$$
4. **Domain Validation**:
   Flags warnings whenever inputs exceed the experimentally verified calibration domain.

## 🚀 Quickstart & Execution Guide

### 1. Activate Environment
In PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Re-run Pipeline (Reproducibility)
```powershell
# Rebuild and validate dataset
python src/data_loader.py

# Generate exploratory figures
python src/visualization.py

# Train models and tune hyperparameters
python src/train.py

# Run evaluation diagnostics
python src/evaluate.py

# Generate SHAP interpretability plots
python src/interpretability.py

# Run parametric sensitivity study
python src/parametric_study.py
```

### 3. Launch Streamlit Dashboard
```powershell
streamlit run app.py
```
Open your browser at `http://localhost:8501`.
